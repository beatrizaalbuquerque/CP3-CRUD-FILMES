# IAs utilizadas

## ChatGPT

### Prompt utilizado

Crie uma aplicação web utilizando apenas HTML, CSS e JavaScript puro.

A aplicação deve representar uma lista de filmes favoritos.

Requisitos obrigatórios:

- Tela de login
- Usuário: aluno
- Senha: fiap2025

Após login correto:
- Mostrar a lista de filmes

A lista deve permitir:
- Adicionar filme no final
- Adicionar filme no início
- Editar filme individualmente
- Remover filme individualmente

Regras obrigatórias:
- Usar array de strings
- Não usar objetos
- Código organizado em funções nomeadas
- Sem frameworks ou bibliotecas externas
- Validar campos vazios
- Se cancelar edição, manter valor original
- Remover item usando índice do array
- Atualizar a tela automaticamente após alterações

A lista deve iniciar com pelo menos 3 filmes cadastrados.

### Problemas encontrados

- Nenhum problema grave encontrado.
